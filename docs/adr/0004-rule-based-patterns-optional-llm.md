# Rule-based patterns, LLM analysis optional and opt-in

Patterns are detected by deterministic rules on the server: free, private, explainable and testable. LLM analysis may come later as an add-on, never a default: an operator configures an OpenAI-compatible endpoint (so a local model works too), each user opts in before any of their transactions leave the instance, and analysis runs on demand per month and is cached. Without opt-in, an operator's key would send a user's private data to a third party.
